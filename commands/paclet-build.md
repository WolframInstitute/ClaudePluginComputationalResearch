Build a Wolfram paclet archive and install locally using the `paclet-build` skill.

Auto-detects the paclet directory (triple or double nesting).
Pass paclet name as argument if ambiguous (e.g., `/paclet-build SyntheticInfrageometry`).

For paclet development, follow `skills/project-create/paclet-design.md`: consult/support the current human-owned `<PacletName>N.nb` and concise `_notes.nb` companion, without advancing the human design or blocking a routine build solely because the notebook is absent.
