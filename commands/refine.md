Shape a backlog item together with the user using the `refine` skill.

The user writes the human parts — Summary, Motivation, Acceptance criteria — in their editor; you research, write the Technical details, keep the open questions, and propose the tasks.
Re-read the item file every turn, since the user is editing it too.
End with the readiness check, and move the item to `Work/Ready/` only when the user says it is ready.

Example: `/refine GraphCurvature`
