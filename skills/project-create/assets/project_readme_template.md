## Folders

`{{CODE_DIR}}/` and `Research/` each have the same three places:

```
Research/
  GeodesicPools_260919.tex      a document in progress
  GeodesicPools_260919_2.tex    its next version
  Artifacts/                    what the plugin made once, on request
  Archive/                      earlier versions, moved aside
```

- **The folder itself** holds the documents in progress: yours, and the ones you write with the plugin, one numbered version per round.
- **`Artifacts/`** holds what the plugin made once, on request, with an index.
- **`Archive/`** holds what is superseded; `/project-clean` moves earlier versions there. Nothing is deleted.

The plugin never overwrites a file.
To keep working on an artifact, move it up into its folder.

`{{CODE_DIR}}/` holds the code and the notebooks about it.
`Research/` holds standalone mathematics: papers, research notebooks, notes.
Papers live in `Research/`; there is no `Paper/` folder.
`Work/` and `Wiki/` are not document folders: `Work/` has its status folders, and `Wiki/` articles are corrected in place.
